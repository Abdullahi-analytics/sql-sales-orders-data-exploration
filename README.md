# SQL Project: Sales Orders Data Exploration and Querying

## Project Overview

This project focuses on querying and exploring a structured orders dataset using SQL to retrieve relevant records, apply filtering conditions, and organise data based on specific business requirements.

The project demonstrates my practical application of fundamental SQL techniques to explore sales-related data, search for specific information, and retrieve records that meet defined criteria. It represents part of my ongoing development in SQL, Data Analytics, and Business Intelligence.

## Project Objectives

The primary objective is to strengthen my ability to work with structured datasets and use SQL to answer specific data-related questions. This includes retrieving selected columns, filtering records using multiple conditions, searching for particular values, and sorting query results for easier interpretation.

## SQL Concepts and Techniques

Throughout this project, I applied the following SQL concepts:

- **SELECT:** Retrieve specific columns from the dataset.
- **WHERE:** Filter records based on defined conditions.
- **AND, OR, and NOT:** Combine or exclude conditions when querying data.
- **LIKE:** Search for text patterns, such as customer names.
- **IN:** Filter records matching values within a specified list.
- **BETWEEN:** Retrieve records within a defined range.
- **ORDER BY:** Sort query results in ascending or descending order.
- **Comparison Operators:** Apply conditions using operators such as `=`, `>`, `<`, `>=`, and `<=`.
- **Date Filtering:** Retrieve records within a specified date range.

## Practical Application

The queries explore different ways to retrieve information from the orders dataset, including filtering orders by country, identifying specific products, examining order quantities, searching customer names using text patterns, and sorting records by relevant fields.

These exercises demonstrate how SQL can be used to move from broad datasets to more specific information based on the requirements of a business question.
